Referencia de clasificación API

El grado API es una medida de qué tan liviano o pesado es el petróleo en relación al agua. Si API > 10, el crudo flota; si API < 10, se hunde.

API → Grav. Específica
SG = 141.5 / (API + 131.5)
Grav. Esp. → API
API = (141.5 / SG) − 131.5
Grav. Esp. → kg/L
kg/L = SG × 0.99904
Grav. Esp. → lb/gal
lb/gal = SG × 8.3278
