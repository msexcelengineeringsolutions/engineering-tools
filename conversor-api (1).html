Fórmulas utilizadas

API → Grav. Específica
SG = 141.5 / (API + 131.5)
Grav. Específica → API
API = (141.5 / SG) − 131.5
Grav. Esp. → kg/L
kg/L = SG × 0.99904
kg/L → kg/m³
kg/m³ = kg/L × 1000
Grav. Esp. → lb/gal
lb/gal = SG × 8.3278
